# Data

The dataset is **not** in this repository. Download it from the team SharePoint folder and save it here.

- Accepted: `.xlsx` or `.csv` with `DM1` in the file name (not the data dictionary).
- Expected columns (from the kickoff slides): 13 numeric covariates (`ctg_repeats`, `somatic_mosaicism_index`, `age`, `age_at_onset`, `disease_duration`, `myotonia_severity`, `muscle_strength`, `pr_interval`, `cognitive_function`, `ck_level`, `insulin_resistance`, `albumin`, `bmi`), 5 categorical (`phenotype`, `sex`, `family_history`, `cataracts`, `smoking_status`), three outcomes (`myotonia_change_12wk`, `qmt_change_26wk`, `tideglusib_composite`) and three responder labels.

Everything in this folder except this file is ignored by git.
