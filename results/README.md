# Official team results

The tables and figures the slides are built from. One copy, so everyone quotes the same numbers.

Produced by the analysis lead, after the team agrees the script and cleaning rules, with:

```bash
cd analysis && DM1_OUT=../results Rscript dm1_analysis.R
```

Everyone else's own runs go to `analysis/dm1_outputs/`, which is not uploaded. See `analysis/README.md` for what each file means.

Empty until the first run on the real dataset.
