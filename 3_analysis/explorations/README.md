# Explorations

One folder per team member. Try ideas here without touching the main script.

- Start from `_template.R` (copy it into your folder and rename it).
- You get **training patients only**, through `load_arm()`. Compare ideas by cross-validation inside the training set (`cv_folds()`), as the template shows.
- Everyone gets the same split and the same cleaned data because both come from `../R/common.R`. Do not copy or change that file.
- When something looks worth keeping, tell the team. If agreed, it moves into `../dm1_analysis.R` and gets a row in `../../DECISIONS.md`.
- If an AI assistant helped, add it to `../../AI_DISCLOSURE.md`.
